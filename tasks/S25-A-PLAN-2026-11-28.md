# S25-A — Normalisation monétaire XOF

## Objectif

Garantir des montants XOF entiers dans DiddiShop sans migration de base :
arrondi vers le haut pour les montants dus et arrondi vers le bas pour les
soldes disponibles.

## Sous-lots

- A — centraliser les fonctions `Decimal` et les validateurs XOF ;
- B — appliquer la règle aux contrats API, domaines, checkout, finance,
  webhooks et adaptateurs externes ;
- C — tester, documenter et préparer la vérification manuelle après déploiement.

## Limites

Les dépôts DiddiPay, DiddiSend et DiddiRewards ne sont pas modifiés. Leurs
équipes doivent appliquer la même politique dans leurs propres runtimes.
