# Plan S14 — Portail documentaire publiable

## Objectif

Permettre au frontend de consulter la documentation depuis une URL publique,
sans lire Git ou le poste de développement, en reprenant le modèle du portail
DiddiGo.

## Sous-lots

- A — construire le site MkDocs en image statique Nginx ;
- B — fournir Compose local et mode public/masqué ;
- C — vérifier les URLs locales, le build strict et documenter le raccordement
  Proxy Host staging.

## Hors périmètre

- configuration distante de Nginx Proxy Manager ;
- création DNS ou certificat TLS ;
- déploiement Portainer staging.
